# Handwritten Digit Recognition using CNN

This project implements a Convolutional Neural Network (CNN) using TensorFlow and Keras to recognize handwritten digits from the MNIST dataset.

## Technologies Used
- Python
- TensorFlow
- Keras
- Matplotlib

## Model Architecture
Conv2D → MaxPooling → Conv2D → MaxPooling → Flatten → Dense → Output

## Accuracy
~98–99% on test dataset
